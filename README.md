# Linha BID para os Fundos de Desenvolvimento Regional

Página estática da Weaver Advisory sobre a linha de US$ 500 milhões do BID para o FDA, o FDNE e o FDCO, com simulador de taxas. Site independente, publicado no GitHub Pages.

- Publicação, cálculo da taxa e manutenção: ver **INSTRUCOES_HERMES.md**.
- Parâmetros do mês: `data/params.json` (TLP pré atualizada automaticamente pelo workflow em `.github/workflows/`).
- IPCA projetado: buscado no boletim Focus do Banco Central a cada visita.
